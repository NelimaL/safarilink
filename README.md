# SafariLink: Data Science and Analytics Capstone

## Project Overview
SafariLink is a fictional Kenyan intercity transport company created for a data science and analytics capstone project. The project uses generated data to analyze passenger bookings, revenue, routes, customer behavior, and transport demand.

## Business Objectives
- Analyze booking and revenue performance across routes.
- Identify peak travel periods and high-performing routes.
- Understand customer booking patterns.
- Forecast future transport demand.
- Develop insights to support business decisions.

## Project Structure
- `data/raw/` — Original generated datasets.
- `data/clean/` — Cleaned and processed datasets.
- `sql/` — SQL scripts for data modeling and analysis.
- `notebooks/` — Exploratory data analysis and modeling.
- `src/` — Reusable Python scripts.
- `dashboard/` — Dashboard files and supporting assets.
- `docs/` — Project documentation and evidence.
- `environment.yml` — Python environment configuration.

## Tools
Python, pandas, SQL, Jupyter Notebook, Git, GitHub, and Power BI.

## Data Disclaimer
SafariLink is fictional. All project data will be generated for educational purposes and will not represent actual company records.
